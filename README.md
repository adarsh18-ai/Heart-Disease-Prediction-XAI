# Heart-Disease-Prediction-XAI
Explainable AI-based Heart Disease Prediction System using Random Forest, SHAP, LIME, and Streamlit for interpretable clinical risk assessment.
❤️ Heart Disease Prediction with Explainable AI

This project is an Explainable Artificial Intelligence (XAI) based Heart Disease Prediction System developed using Machine Learning, SHAP, LIME, and Streamlit.

The system predicts the probability of heart disease based on patient clinical parameters and provides interpretable explanations for the prediction using SHAP and LIME.

Features:
1) Heart Disease Risk Prediction
2) Random Forest Classifier
3) Probability-based Risk Assessment
4) SHAP Feature Importance Analysis
5) LIME Local Interpretability
6) Clinician-Friendly Explanations
7) Interactive Streamlit Dashboard
